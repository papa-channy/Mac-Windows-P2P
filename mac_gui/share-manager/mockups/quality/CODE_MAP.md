# CODE_MAP — 식별자 트리 (M2)

모든 leaf 가 `<UPPER>-<NUMBER>-<lower>` 식별자를 갖는다. 형식 / 도메인
정의 / decision tree / tie-breaker 는 [TAXONOMY.md](./TAXONOMY.md) 참조.

각 leaf 의 라인 형식:
```
<id> · <짧은 이름> — file:line · kind
   consumes: <식별자>... · emits: <식별자>... · meta: <라벨>
```
파일 라인이 없거나(아직 미구현) 적용 없는 필드는 생략.

상태(`Status`)는 IMPL_STATUS.md (M3) 에서 별도 추적 — 이 파일은
**식별자 부여 + 위치 + 관계망**만 담는다.
